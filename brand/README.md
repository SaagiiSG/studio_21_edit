# Brand

Put Saagii's brand guidelines here. Claude reads `brand/BRAND.md` before any design work and uses it over
any default.

Expected files:

```
brand/
  BRAND.md          the guide (sections below)
  logo.svg          vector logo (PNG fallback: logo.png, transparent, ≥ 1000 px)
  fonts/            .woff2 / .ttf files you have the right to use
  refs/             screenshots or videos of reels you like (optional)
```

`BRAND.md` sections (short bullets are fine):

- **Name / handle:** what goes on the end card (@handle, site, "DM me").
- **Colors:** hex + role (background, text, primary emphasis, secondary, warning/negative).
- **Type:** headline font, body/label font, caption font, case (UPPER / Title).
- **Captions:** size, box or no box, highlight colors and when to use them, max words per chunk.
- **Motion:** feel (snappy / smooth / minimal), transitions you like and hate.
- **Sound:** music mood, SFX palette (soft clicks vs punchy hits), or "no music".
- **Do / Don't:** anything that should never appear.

Client work (e.g. Arson Wraps) uses the client's brand inside that project's `DESIGN.md`, not this folder.
